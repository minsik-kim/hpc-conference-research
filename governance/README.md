# governance/

This directory defines how the knowledge base is built, trusted, and
extended. Read `KNOWLEDGE_BASE_RULES.md` and `ANTI_HALLUCINATION_RULES.md`
first; they are the two files every other rule here builds on.

- `KNOWLEDGE_BASE_RULES.md` — core operating principles for the whole repo
- `SOURCE_EVIDENCE_RULES.md` — provenance hierarchy, publication-type rules
- `ANTI_HALLUCINATION_RULES.md` — grounding states, mandatory principles
- `ID_NAMING_RULES.md` — stable source ID policy
- `CONFERENCE_IMPORT_WORKFLOW.md` — adding a new conference/source set
- `TOPIC_UPDATE_WORKFLOW.md` — updating topics when one new source arrives
- `RESEARCH_GAP_RULES.md` — proposing and falsifying a research gap
- `VERSIONING_CHANGELOG_RULES.md` — versioning and changelog conventions
- `GPT_RETRIEVAL_GUIDE.md` — the retrieval workflow for a new session

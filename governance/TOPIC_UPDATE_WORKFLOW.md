# TOPIC_UPDATE_WORKFLOW

Adding one new source does not justify rewriting every topic document.

```
new source
      ↓
identify affected topics
      ↓
rebuild generated paper maps/indexes
      ↓
check mechanism/lineage impact
      ↓
update only the affected curated documents
```

A topic document is "affected" only if the new source changes its problem
landscape, mechanism families, representative papers, lineage, or open
questions — not merely because the new source is topically adjacent.

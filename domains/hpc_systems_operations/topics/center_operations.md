# center_operations.md

**Note:** created per the explicit allowance in the import instructions to add a center-profile topic "only if it has real retrieval value" — `raw/H_centers.md` is a 743-line document profiling 15+ centers and is cited from nearly every other topic file in this domain as the primary practitioner-evidence source; a dedicated index into it has clear retrieval value. This file is a routing/index layer, not a duplicate of `H_centers.md`'s content.

## Scope

Cross-cutting index into `corpus/aiops-survey/raw/H_centers.md` [PRACTITIONER] — the corpus's single largest practitioner-evidence document, profiling 15+ production HPC centers' operational stacks across telemetry, scheduling, fabric, storage, GPU, power/cooling, and remediation practice.

## Why this is separate from the other topic files

Each other topic file (`telemetry_observability`, `fabric_operations`, `storage_io_operations`, `gpu_operations`, `power_cooling`, `automated_remediation`, etc.) cites `H_centers.md` for its slice of what centers report. This file exists for the opposite query direction: "what does center X report across *all* operational areas" — a per-center rather than per-topic view. It does not restate center-specific content (doing so would create a second, driftable copy); it exists so a reader knows `H_centers.md` is the single document to open for any cross-topic, center-specific question.

## Evidence type

All content in `H_centers.md` is **production/practitioner evidence** — centers' own self-reported operational descriptions — not peer-reviewed research. Per `DOMAIN_CONTEXT.md`, a center's practice (however sophisticated) is not thereby a validated research result, and should be cited as `[PRACTITIONER]` evidence about that specific site.

## Evidence limitations

`H_centers.md` is a single-pass census (part of the initial `A`–`H` phase); it was not independently re-verified center-by-center in the `V1`–`V8` verification round (which focused on specific named external systems/papers, not on re-confirming center self-reports). Treat its content as un-re-verified initial census, per `evidence/EVIDENCE_LINEAGE.md`.

## Canonical deeper source

`raw/H_centers.md` (the only document for this topic).

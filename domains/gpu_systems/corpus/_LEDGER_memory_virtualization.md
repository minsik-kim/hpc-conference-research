## How access states were determined in this pass

- **Reachable from this environment:** author/group-hosted PDFs (`csa.iisc.ac.in`, `users.elis.ugent.be`, `sarchlab.org`), NSF-PAR (`par.nsf.gov`), arXiv (`/abs/` and `/html/<id>v1`), conference-hosted proceedings PDFs (`hpcrl.github.io/ICS2025-webpage/...`), Elsevier Pure / institutional research-portal pages (`yonsei.elsevierpure.com`, `pure.psu.edu`), author publication pages, and GitHub over Bash.
- **Not reachable (do not retry):** `dl.acm.org` → HTTP 403 (verified again in this pass on the HELM `doi/full` URL); `ieeexplore.ieee.org` → HTTP 418; `dblp.org` → robots-disallowed; `arxiv.org/search` and `export.arxiv.org` → unavailable; `web.archive.org` → blocked.
- `PENDING_FULLTEXT` is used where an **open-access-form publisher URL was observed** (`dl.acm.org/doi/full/...` or `/doi/pdf/...`) but the host is blocked here — those papers are likely obtainable elsewhere and should be retried from an environment with ACM access. `CLOSED_ACCESS` is used where **no public copy was located at all** and the only records are paywalled.

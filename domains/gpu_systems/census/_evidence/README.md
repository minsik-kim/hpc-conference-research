# census/_evidence/ — raw program extracts

Raw, unedited extracts captured while reconstructing venue-year populations,
kept so that a later session can re-derive a count without re-fetching a page
that may have changed or become unreachable. The same role that
`domains/hpc_quantum/corpus/quantum-hpc-survey/working-evidence/` plays for
that domain.

These are **`[official-program]` evidence, not analyses.** A title appearing
here means the program page listed it; it says nothing about the paper's GPU
relevance, and it is never a substitute for the census file's own §1 or §2.

Current contents are ASPLOS program dumps for 2024–2026. One is explicitly
marked truncated: the official ASPLOS 2024 main-program page stops after
session 8C, which is why that venue-year's screening coverage is 71% and why
its census status is `PARTIAL_CENSUS`.

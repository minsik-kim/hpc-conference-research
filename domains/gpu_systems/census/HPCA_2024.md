### 1.1 Population evidence notes

Source statement: the official main-program page enumerates 81 paper entries across 13 paper
sessions (1A/1B/1C, 2A/2B/2C, 3A/3B/3C, 5A/5B/5C, 6A/6B/6C, 7A/7B/7C, Session 9, 10A/10B/10C).
Session numbering skips 4 and 8 (keynote/panel/social slots).

Inference: 81 program entries − 3 Best of CAL − 3 Industrial Track = **75** regular research
papers. This is independently corroborated two ways: (a) the DBLP-derived researchr proceedings
TOC also contains exactly 81 entries, with the same 3 Best of CAL items (A Quantum Computer
Trusted Execution Environment; Unleashing the Potential of PIM; Computational CXL-Memory
Solution) and the same 3 Industrial items (An LPDDR-based CXL-PNM Platform; LightPool;
Enterprise-Class Cache Compression Design); (b) a published acceptance statistic of 75/410
(18.3%).

HPCA 2024 used a two-cycle submission process. The official program does not label papers by
cycle, so a single main-program total is reported and no per-cycle split is claimed.

Title discrepancies observed between the official program page and the proceedings TOC (the
proceedings/DBLP title is treated as official):
- program "Tetris: Boosting Distributed DNN Execution with Flexible Schedule Search" →
  proceedings "Tessel: Boosting Distributed Execution of Large DNN Models via Flexible Schedule Search"
- program "PruneGNN: An Optimized Algorithm-Hardware Framework for Graph Neural Network Pruning" →
  proceedings "PruneGNN: Algorithm-Architecture Pruning Framework for Graph Neural Network Acceleration"
- program "BeaconGNN: Large-Scale GNN Acceleration with Asynchronous In-Storage Computing" →
  proceedings "... with Out-of-Order Streaming In-Storage Computing"

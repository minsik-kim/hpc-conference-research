## 6. Unresolved / blocked items

- **IEEE Xplore unreachable.** `ieeexplore.ieee.org` returns **HTTP 418** through this proxy for `/document/<id>/` and `/xpl/conhome/...`. Consequence: **no per-paper DOIs and no verified publisher URLs for any ISC 2025 research paper.** Three document numbers (11017726, 11018268, 11018306) came from search-engine result titles only.
- **No independent bibliographic corroboration was possible:** dblp (`dblp.org`, `dblp.dagstuhl.de`) robots-disallowed; `dl.acm.org` 403; Crossref REST API returned `total-results: 0` for the ISC container title; `scholar.archive.org` rate-limited; `fatcat.wiki` robots.txt timeout; `scilit.com` 403; `ouci.dntb.gov.ua` search not URL-addressable.
- **Workshop volume paper count** (Springer LNCS 16091) is UNKNOWN — the volume page reached named several workshops but did not give a total.
- **Per-class counts** for tutorials, BoFs, posters, PhD Forum, HPC in Asia, Industrial Day are UNKNOWN.
- **Artifact/code URLs**: per the budget prioritisation rule, searched only for the GPU-*mechanism* candidates (#1 energy/frequency, #2 communication/topology, #11 power); all `NOT_FOUND_AFTER_SEARCH`. All domain-application acceleration candidates are `NOT_SEARCHED (deprioritised)`.
- Eight of the eleven candidates are `[TITLE-ONLY]` + session-label inferences; their GPU centrality needs an abstract to confirm, which requires IEEE Xplore.
